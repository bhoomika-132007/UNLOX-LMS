# Handwritten Digit Recognition Using CNN

**Student Name:** Bhoomika  
**Project Type:** Engineering Minor Project  
**Technology:** Python, TensorFlow, CNN, Streamlit

## Project Overview
This project implements a Handwritten Digit Recognition system using a Convolutional Neural Network (CNN). It uses the MNIST dataset containing handwritten digits from 0 to 9.

The trained CNN model predicts handwritten digits from uploaded images through a Streamlit web application.

## Technologies Used
- Python
- TensorFlow and Keras
- Convolutional Neural Network (CNN)
- NumPy
- Matplotlib
- Streamlit
- MNIST Dataset

## Project Features
1. MNIST dataset loading and preprocessing.
2. CNN model construction and training.
3. Training and validation accuracy/loss graphs.
4. Model evaluation and confusion matrix.
5. Upload handwritten digit images.
6. Predict digits from 0 to 9.
7. Display prediction confidence and class probabilities.

## How to Use the Application
1. Open the live application using the link below.
2. Upload a handwritten digit image in PNG or JPG format.
3. The application processes the image.
4. View the predicted digit and prediction confidence.
